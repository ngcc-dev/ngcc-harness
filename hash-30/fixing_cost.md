## Remediation

- **hash-30-1.** Root cause: the ZC-1536 linear layer fixes the difference 0x1111111111111111 in A0[0]. ρ leaves plane 0 in place, and the two θ parity shifts, 20 and 56 (physical p. 9), differ by 36, so the two rotated copies cancel on a lane pattern of period 4. The costed repair is the submitters' proposal as report.md records it: the ZC-DM team's v1.1 notice revises the first θ parity shift. θ still rotates each parity lane twice, so no operation is added. Scope: Single line, specification and code. Impact: none. report.md marks the revision as not evaluated. The notice itself was not read, and whether the revised shift leaves other sparse fixed differences was not checked.
- **hash-30-2.** Root cause: the plane-2 offset (5, 0) (physical p. 9) has no z-rotation. ρ applied twice moves plane 2 by (10, 0) ≡ (2, 0) on the 8 × 64 lane grid, so a difference on four plane-2 lanes at one z returns to itself and shares columns with four bits of the unmoved plane 0 in between. The costed repair is the submitters' proposal as report.md records it: v1.1 changes the plane-2 offset to (5, 1) in both shift layers. The eight plane-2 lanes, which ρ only moves in the submitted code, are then also rotated in both ρ steps: +16 lane rotations per round, in all three ZC-1536 instances because they share Algorithm 2. Scope: Function, specification and code. Impact: hashing per byte +10% (estimate: 16 rotations added to 153 logic operations per round is +10.5%, and +10.2% per block with the mode's XORs), with a range of +5% to +12% by counting convention; a one-block message has the same ratio because every permutation call changes. The estimate passes 10% by a small margin. It falls to +9.4% if the reference code's byte-wise feed-forward loop is counted byte by byte, and to +4.7% if every lane read and write of the reference code is counted as work; either would change the answer with leads to No. Not costed: a rotation in one ρ layer only (+8 per round), which no source proposes.
- **hash-30-3.** Root cause: the ZC-1280 linear layer fixes a difference on eight χ columns. A difference of that shape follows from the plane-2 offset: ρ applied twice moves plane 2 by 2 × (3, 24) ≡ (2, 48) on the 4 × 64 lane grid, a shift of order 4, so four plane-2 bits return to themselves and share columns with four bits of the unmoved plane 0 in between. The costed repair is the submitters' proposal as report.md records it: v1.1 changes the second plane shift on planes 1, 2 and 4. Every lane of planes 1 to 4 is already rotated in each ρ step, so new offsets add no operation; the code needs a second ρ routine or an offset argument. Scope: Function, specification and code. Impact: none. report.md does not give the revised offsets and they were not checked. The attachment of issue #37 was not read, so the match between the shape above and the reported difference rests on the report's description.

## Evidence

- Baseline: Table 1.2 (physical p. 13) gives c = n + 64 and r = m − c, that is 704, 448 and 192 bits for ZC-1280 and 960, 704 and 448 bits for ZC-1536; control 1536 − (512 + 64) = 960.
