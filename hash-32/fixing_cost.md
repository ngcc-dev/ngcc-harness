## Attacks considered

- hash-32-2: Message modification gives a conditional 2^288 collision estimate (Design, Lead)

## Remediation

- **hash-32-2.** Root cause: the ZC-1536 linear layer fixes the difference 0x1111111111111111 in A0[0]. ρ leaves plane 0 in place, and the two θ parity shifts, 20 and 56 (physical p. 9), differ by 36, so the two rotated copies cancel on every lane pattern of period gcd(36, 64) = 4. report.md records the ZC-DM team's v1.1 notice as a proposed fix; the specification attached to it is by the nine authors of ZC-EDMC and revises the ZC-1280 and ZC-1536 permutations that ZC-EDMC shares; no ZC-EDMC revision has been posted. Its values are quoted, not evaluated. The costed repair is the v1.1 value of θ: the first parity shift becomes (1, 23), and the second stays (1, 56). The shifts then differ by 33, which is odd, so the two copies cancel only on an all-zero or all-one lane, and the linear layer no longer fixes 0x1111111111111111, whether the plane shifts are the submitted ones or those of v1.1 (the helper gives an image of weight 112 in both cases); with the submitted θ the difference stays fixed under either plane shift. θ still rotates each parity lane twice, so no operation is added. The round function is shared by both six-round halves, so the repair is the same for the specified mapping and the implemented one. Scope: Single line, specification and code. Impact: none. The v1.1 revision also changes the ZC-1536 plane-2 offset from (5, 0) to (5, 1) in both plane shifts. That change does not bear on this difference, so it is not part of the costed repair; adopted with the rest of v1.1, it would rotate the eight plane-2 lanes in both plane shifts, +16 lane rotations per ZC-1536 round, +10.5% of the 153 logic operations of a round (count). With the submitted plane shifts the linear layer still fixes other differences of 8 bits (helper); no finding in this report rests on them, and they were not costed. Not checked: trails in which χ changes the difference, iterative trails over several rounds, and the bounds of the revised permutation.
- **hash-32-3.** Root cause: the ZC-1280 linear layer fixes a difference on eight χ columns. A difference of that shape follows from the plane-2 offset: ρ applied twice moves plane 2 by 2 × (3, 24) ≡ (2, 48) on the 4 × 64 lane grid, a shift of order 4, so four plane-2 bits return to themselves and share columns with four bits of the unmoved plane 0 in between. The helper builds this 8-bit difference, which lies wholly in the 704-bit rate when its plane-2 bits are in lanes 0 and 2, and confirms that the submitted layer fixes it at all 256 start positions. The costed repair is the second plane shift of ZC-1280 in the same v1.1 revision, ρ′ = (2, 9), (3, 25), (0, 1) and (2, 4) on planes 1 to 4, with the first plane shift and θ unchanged. The two shifts then move plane 2 by (2, 49), of order 64, and the revised layer fixes the 8-bit difference at none of the 256 start positions. Every lane of planes 1 to 4 is already rotated in each plane shift, and each v1.1 offset of ρ′ rotates by a nonzero amount, so the new offsets add no operation; the code needs a second plane-shift routine with the new constants. The round function is shared by both six-round halves, so the repair is the same for the specified mapping and the implemented one. Scope: Function, specification and code. Impact: none. The attachment of issue #37 was not read, so the reported difference was not compared with the one built here. The revised ZC-1280 layer fixes no nonzero difference of fewer than 64 bits, and with at most 5 bits in a column such a difference covers at least 13 columns, so it fixes no difference on eight columns. Not checked: as for hash-32-2. Nothing was implemented or measured.
