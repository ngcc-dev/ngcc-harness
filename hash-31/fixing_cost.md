## Attacks considered

- hash-31-2: Message modification gives a conditional 2^288 collision estimate (Design, Lead)

## Remediation

- **hash-31-2.** Root cause: the ZC-1536 linear layer fixes the difference 0x1111111111111111 in A0[0]. ρ leaves plane 0 in place, and the two θ parity shifts, 20 and 56 (physical p. 9), differ by 36, so the two rotated copies cancel on every lane pattern of period gcd(36, 64) = 4. report.md records the ZC-DM team's v1.1 notice as a proposed fix; the specification attached to it is by the nine authors of ZC-DMC and revises the ZC-1280 and ZC-1536 permutations that ZC-DMC shares; no ZC-DMC revision has been posted. Its values are quoted, not evaluated. The costed repair is the v1.1 value of θ: the first parity shift becomes (1, 23), and the second stays (1, 56). The shifts then differ by 33, which is odd, so the two copies cancel only on an all-zero or all-one lane, and the revised linear layer no longer fixes 0x1111111111111111 (the helper gives an image of weight 112). The helper also shows that the θ value is the part of v1.1 that does this: with the v1.1 plane shifts and the submitted θ the difference is still fixed. θ still rotates each parity lane twice, so no operation is added. Scope: Single line, specification and code. Impact: none. Not checked here or for the other two findings: trails in which χ changes the difference, iterative trails over several rounds, and the bounds of the revised permutations; the revised layers still fix some differences, none lighter than 64 bits (Evidence), and whether any gives a trail was not checked.
- **hash-31-3.** Root cause: the plane-2 offset (5, 0) (physical p. 9) has no z-rotation. ρ applied twice moves plane 2 by (10, 0) ≡ (2, 0) on the 8 × 64 lane grid, a shift of order 4, so a difference on four plane-2 lanes at one z returns to itself and shares columns with four bits of the unmoved plane 0 in between. The costed repair is the plane-2 offset of the same v1.1 revision, (5, 1), in both plane shifts, which v1.1 keeps equal for ZC-1536. The two shifts then move plane 2 by (2, 2), of order 32, and the revised linear layer fixes none of the 8-column patterns D, E and W at any of the 64 values of z, where the submitted layer fixes all three at every z; the v1.1 θ value alone leaves them fixed. Lane rotation in ρ is the specification's own means against differences confined to a slice (physical p. 17; §2.2.3, physical p. 19), and the specification applies one ρ before and one after θ (physical p. 10). The eight plane-2 lanes, which ρ only moves in the submitted code, are then also rotated in both ρ steps: +16 lane rotations per round, in all three ZC-1536 instances because they share Algorithm 2. Scope: Function, specification and code. Impact: hashing per byte +10% (estimate: 16 rotations added to 153 logic operations per round is +10.5%, and +10.3% per block with the mode's XORs), with a range of +5% to +12% by counting convention; a one-block message has the same ratio because every permutation call changes. The estimate passes 10% by a small margin. It falls to +4.7% if every lane read and write of the reference code is counted as work, and that would change the answer with leads to No. Not costed: a rotation in one ρ layer only (+8 per round), which would make the two ZC-1536 plane shifts differ; v1.1 keeps them equal, and no source proposes it. A plane-2 offset (a, 0) without a z-rotation would add no operation but leaves the root cause: two plane shifts then move plane 2 by (2a, 0), whose orbit stays at one z, and the helper finds a fixed difference of 2 to 8 bits for each of the eight values of a.
- **hash-31-4.** Root cause: the ZC-1280 linear layer fixes a difference on eight χ columns. A difference of that shape follows from the plane-2 offset: ρ applied twice moves plane 2 by 2 × (3, 24) ≡ (2, 48) on the 4 × 64 lane grid, a shift of order 4, so four plane-2 bits return to themselves and share columns with four bits of the unmoved plane 0 in between. The helper builds this 8-bit difference, which lies wholly in the 704-bit rate when its plane-2 bits are in lanes 0 and 2, and confirms that the submitted layer fixes it at all 256 start positions. The costed repair is the second plane shift of ZC-1280 in the same v1.1 revision, ρ′ = (2, 9), (3, 25), (0, 1) and (2, 4) on planes 1 to 4, with the first plane shift and θ unchanged. The two shifts then move plane 2 by (2, 49), of order 64, and the revised layer fixes the 8-bit difference at none of the 256 start positions. Every lane of planes 1 to 4 is already rotated in each plane shift, and each v1.1 offset of ρ′ rotates by a nonzero amount, so the new offsets add no operation; the code needs a second plane-shift routine with the new constants. Scope: Function, specification and code. Impact: none. The attachment of issue #37 was not read, so the reported difference was not compared with the one built here. The revised ZC-1280 layer fixes no nonzero difference of fewer than 64 bits, and with at most 5 bits in a column such a difference covers at least 13 columns, so it fixes no difference on eight columns. Nothing was implemented or measured.
