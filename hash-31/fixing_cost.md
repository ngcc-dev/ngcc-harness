## Remediation

- **hash-31-2.** Root cause: the ZC-1536 linear layer fixes the difference 0x1111111111111111 in A0[0]. ρ leaves plane 0 in place, and the two θ parity shifts, 20 and 56 (physical p. 9), differ by 36, so the two rotated copies cancel on a lane pattern of period 4. report.md records the ZC-DM team's v1.1 notice, which revises the shift offsets of the shared permutations for ZC-DM only; no ZC-DMC revision has been posted. The costed repair is a standard change of a constant: one θ parity shift is replaced so that the two copies no longer cancel on that pattern. θ still rotates each parity lane twice, so no operation is added. Scope: Single line, specification and code. Impact: none. No replacement shift was chosen, and whether one leaves other sparse fixed differences was not checked.
- **hash-31-3.** Root cause: the plane-2 offset (5, 0) (physical p. 9) has no z-rotation. ρ applied twice moves plane 2 by (10, 0) ≡ (2, 0) on the 8 × 64 lane grid, so a difference on four plane-2 lanes at one z returns to itself and shares columns with four bits of the unmoved plane 0 in between. report.md records the ZC-DM team's v1.1 notice, which revises the shift offsets of the shared permutations for ZC-DM only; no ZC-DMC revision has been posted. The costed repair is a standard change of a constant: a nonzero z-offset for plane 2 in ρ. Lane rotation in ρ is the specification's own means against differences confined to a slice (physical p. 17; §2.2.3, physical p. 19), and the specification applies one ρ before and after θ (physical p. 10). The eight plane-2 lanes, which ρ only moves in the submitted code, are then also rotated in both ρ steps: +16 lane rotations per round, in all three ZC-1536 instances because they share Algorithm 2. Scope: Function, specification and code. Impact: hashing per byte +10% (estimate: 16 rotations added to 153 logic operations per round is +10.5%, and +10.3% per block with the mode's XORs), with a range of +5% to +12% by counting convention; a one-block message has the same ratio because every permutation call changes. The estimate passes 10% by a small margin. It falls to +4.7% if every lane read and write of the reference code is counted as work, and that would change the answer with leads to No. Not costed: a rotation in one ρ layer only (+8 per round), which makes the two ρ steps differ and which no source proposes. No offset was chosen or checked.
- **hash-31-4.** Root cause: the ZC-1280 linear layer fixes a difference on eight χ columns. A difference of that shape follows from the plane-2 offset: ρ applied twice moves plane 2 by 2 × (3, 24) ≡ (2, 48) on the 4 × 64 lane grid, a shift of order 4, so four plane-2 bits return to themselves and share columns with four bits of the unmoved plane 0 in between. report.md records the ZC-DM team's v1.1 notice, which revises the shift offsets of the shared permutations for ZC-DM only; no ZC-DMC revision has been posted. The costed repair is a standard change of constants: new ρ offsets for ZC-1280, at least on plane 2. Every lane of planes 1 to 4 is already rotated in each ρ step, so new offsets add no operation. Scope: Function, specification and code. Impact: none. No offsets were chosen or checked. The attachment of issue #37 was not read, so the match between the shape above and the reported difference rests on the report's description.

## Evidence

- Baseline: Table 1.2 (physical p. 14) gives c = n + 64, r = m − c and r′ = 64, that is r = 704, 448 and 192 bits for ZC-1280 and 960, 704 and 448 bits for ZC-1536; control 1536 − (512 + 64) = 960. Absorption makes one 12-round ZC-m call per r-bit block, and squeezing makes n/64 − 1 further calls (Algorithm 3, physical p. 15; `ZC-DMC/Implementations/Implementations/Reference_Implementation/ZC-DMC-1536-512/CryptHash_AlgorithmInstance.c:26,86,117,121,125`). No repair changes the rates, the rounds or the calls. A hash has no bandwidth.
- The specification gives batch run times only (Table 4.1, physical p. 31) and no breakdown by step, so the operation counts are the whole evidence. §4.1.1 (physical p. 29) names XOR, rotations and AND as the operations that set the speed. Nothing was measured.
- ZC-1536 round, Algorithm 2 (physical p. 11) and `ZC-DMC/Implementations/lib/low/ZuD-1536/plain/ZuD1536-plain.c`: ι 1 XOR (:214); χ 8 sheets × (3 NOT, 3 AND, 3 XOR) = 72 (:227–229); ρ 8 ROTL64 on plane 1 and 8 unrotated moves on plane 2 (:192–207), called twice (:267, :269); θ 48 XOR and 16 ROTL64 (:155–179). Total 73 XOR + 24 AND + 24 NOT + 32 ROTL64 = 153 logic operations. Lane reads and writes as written: θ 72, ρ 64, χ 48, ι 2 = 186.
